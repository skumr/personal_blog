### website_v1
This is the first version of my personal website project.

## Server-side

This website is built using Flask. 

## Front-end

So far we have just html that is being rendered by jinja template extensions.

## Website Strucutre

1. Home Page

The Home page will display the last post made. It will also include an text box and submission button to create a post. After a post has been created the home page will update with that latest post.

2. Posts

The Posts page will display all posts ever made. It will display all posts in a listed format, in descending order, starting from the latest post. Here, a post can be edited and/or deleted. 

3. About

The About page will dispaly a description of the site and its purpose.
